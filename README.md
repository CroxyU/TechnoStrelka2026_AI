Telegram-бот для умного поиска по книгам с использованием RAG (Retrieval-Augmented Generation).  
Позволяет загружать книги в формате `.txt`, искать релевантные фрагменты и задавать вопросы — бот отвечает, опираясь только на найденные отрывки.

## Краткое описание решения

Бот реализует архитектуру RAG:

1. **Индексация книг**  
   - Книги загружаются через Telegram или из папки `standard_books`.  
   - Текст очищается, разбивается на главы (или логические блоки) и затем на маленькие дочерние чанки (для точного поиска) и большие родительские блоки (для полного контекста).  
   - Для каждого чанка генерируются эмбеддинги с помощью `sentence-transformers`.  
   - Чанки и родительские документы сохраняются в ChromaDB (векторная база данных).

2. **Поиск**  
   - Гибридный поиск: объединяет векторный поиск (смысловое сходство) и BM25 (точное совпадение слов).  
   - Расширение запросов (query expansion) через Groq: LLM генерирует синонимы и перефразирования, чтобы увеличить полноту поиска.  
   - По найденным дочерним чанкам извлекаются соответствующие родительские документы (целые главы) и возвращаются пользователю.

3. **Генерация ответов**  
   - Найденные родительские документы передаются в Groq вместе с вопросом.  
   - LLM формирует ответ, используя только предоставленный контекст.  
   - В ответе также приводятся исходные цитаты и числовая релевантность.

## Стек технологий

| Компонент          | Используемое решение                          |
|--------------------|-----------------------------------------------|
| **Язык**           | Python 3.12                                    |
| **Telegram API**   | `python-telegram-bot` (asyncio)                |
| **Эмбеддинги**     | `sentence-transformers` (intfloat/multilingual-e5-large)     |
| **Векторная БД**   | ChromaDB (persistent)                          |
| **Гибридный поиск**| BM25 (`rank-bm25`) + векторный                |
| **Токенизация**    | NLTK (русский)                                 |
| **LLM**            | Groq (модель llama-3.3-70b-versatile)          |
| **Расширение запросов** | Groq (генерация синонимов/перефразирований) |
| **Интерфейс**      | HTML‑разметка, inline‑кнопки, пагинация        |

## Команды
📖 Справка по командам

### Основные команды:
- `/start` – приветствие и главное меню
- `/help – это сообщение`
- `/search [запрос]` – поиск фрагментов (например, /search Наташа Ростова)
- `/ask [вопрос]` – задать вопрос по книгам (например, /ask Кто такой Пьер?)
- `/addbook` – загрузить новую книгу (отправьте .txt файл после команды)
- `/listbooks` – показать список всех загруженных книг

### Административные команды:
- `/cleardb` – полностью очистить базу данных (с подтверждением)
- `/reset` – сбросить базу к стандартному набору книг

## Как запустить сервис
На компьютере/серверк должен присутствовать Python

1. **Клонировать репозиторий**
   
-    `git clone https://github.com/CroxyU/TechnoStrelka2026_AI.git`
   
-    `cd TechnoStrelka2026_AI`

2. **Создать и активировать виртуальное окружение**

`python -m venv .venv`

3. **Установить зависимости**
   
`pip install -r requirements.txt`

4. **Настроить переменные окружения**  
Создайте файл `.env` в корне проекта и добавьте:

BOT_TOKEN=ваш_токен_бота

API_KEY=ваш_ключ_groq

6. **Запустить бота**

`python -m bot.main`

---

## Как загрузить тексты книг

1. **Через команду `/addbook`**  
 - Отправьте боту команду `/addbook`.  
 - После запроса отправьте файл в формате `.txt`.  
 - Бот автоматически обработает книгу, разобьёт на иерархические чанки и проиндексирует.

2. **Через папку `standard_books` (В репозитории представлено несколько тестовых книг!)**
 - Положите в неё один или несколько файлов `.txt`.  
 - Выполните команду `/reset` – база очистится, и все книги из этой папки будут загружены и проиндексированы.
Внимание! Эта команда может занимать много времени!

## Примечания

- **Кодировка файлов** должна быть UTF-8 (или автоматически определяемая).
- **Модель эмбеддингов** загружается один раз при первом обращении.
- **База данных ChromaDB** хранится в папке `chroma_data`. При необходимости её можно удалить вручную или через команду `/cleardb`.
- **Groq API** имеет ограничения на бесплатном тарифе (30 запросов/мин, 500k токенов/день). При превышении бот выводит сообщение.

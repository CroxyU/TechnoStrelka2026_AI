# TechnoStrelka2026_AI 📚🤖
Решение кейса отборочного этапа "Технострелка 2026" по направлению исскуственнный интеллект командой БЯМ_БЯМ_БЯМ-38
Telegram-бот для умного поиска по книгам с использованием RAG (Retrieval-Augmented Generation).  
Позволяет загружать книги в формате `.txt`, искать релевантные фрагменты по запросу и задавать вопросы по содержанию — бот отвечает, опираясь только на найденные фрагменты.

---

## Возможности

- 🔍 **Поиск фрагментов** – команда `/search <запрос>` возвращает 3–5 самых релевантных отрывков с указанием книги и главы.
- ❓ **Ответы на вопросы** – команда `/ask <вопрос>` формирует ответ с помощью LLM (Groq) на основе найденных фрагментов; в ответе также приводятся исходные цитаты.
- 📥 **Загрузка новых книг** – команда `/addbook` позволяет отправить боту `.txt` файл, который автоматически разбивается на чанки, индексируется и добавляется в векторную базу.
- 📚 **Список книг** – команда `/listbooks` показывает все загруженные в систему книги.
- 🧹 **Очистка базы** – команда `/cleardb` (доступна администраторам) полностью удаляет все книги из базы (с подтверждением).
- 🔄 **Сброс к стандартным книгам** – команда `/reset` очищает базу и загружает предустановленный набор книг из папки `standard_books`.
- 🎛 **Удобный интерфейс** – клавиатура с основными командами, индикация "печатает...", пагинация результатов поиска.

---

## Технологии

- **Язык**: Python 3.12
- **Библиотека для Telegram**: `python-telegram-bot` (asyncio)
- **Эмбеддинги**: `sentence-transformers` (модель `all-MiniLM-L6-v2`)
- **Векторная база данных**: `chromadb` (persistent)
- **Гибридный поиск**: `rank-bm25` (BM25) + векторный поиск
- **Токенизация**: `nltk` (русский язык)
- **LLM**: `groq` (модель `llama-3.3-70b-versatile`)
- **Дополнительно**: `python-dotenv`, `requests`, `tqdm`, `numpy`
